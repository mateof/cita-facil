# Capturas

Imágenes de la aplicación que se enlazan desde el README y desde la
documentación.

Están tomadas con los **datos de ejemplo** que crea `npm run seed`, así que
cualquiera puede reproducirlas: la organización es "Peluquería Ejemplo", el
personal es Ana Ríos y Carlos Vidal, y la clienta es Lucía Pena. No hay datos
reales de nadie.

Si al cambiar la interfaz alguna se queda desfasada, se vuelve a tomar sobre el
mismo escenario para que la documentación no enseñe algo que ya no existe.
